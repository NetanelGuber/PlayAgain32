# Security

This is an experimental alpha, with no production support or external security audit. Only the current `main` development version receives fixes. Game APKs contain executable code: import files from sources you trust. Translation is not a security sandbox.

Report vulnerabilities privately through [GitHub security advisories](https://github.com/OTAKUWeBer/PlayAgain32/security/advisories/new). If private reporting is unavailable, open a minimal issue asking for a private reporting channel without exploit details or sensitive files.

Include the affected revision, Android/device details, reproduction steps and a minimal legal test case. Do not send signing keys, credentials or commercial game files. Redact personal information in diagnostics.

The manager does not request Internet access. Installed games retain their own permissions and behavior. Do not treat offline operation as a guarantee that imported games are safe.
